# CodeForge v1.0.0 Release Notes

**CodeForge: Mobile-First Collaborative Cloud IDE & Engineering Cockpit**

### ✦ Highlights

- **Claude AI-Inspired Minimalist UX**: Warm terracotta palette, clean typography, soft card borders, and responsive design.
- **DevEngine Intelligent Auto-Correction**: Neural code repair pipeline powered invisibly under the hood by Gemini with offline heuristic fallbacks.
- **AI Model Connectors**: Support for connecting Claude (Anthropic), ChatGPT (OpenAI), Grok (xAI), and local Ollama instances.
- **Direct GitHub Push**: Integrated remote repository sync with commit composer, staging area, and branch tracking.
- **Full Offline & Online Support**: Seamless offline sandbox mode with queued commits and sync.
- **Interactive Shell Terminal**: Real-time command executor for `git`, `npm`, `python`, `cargo`, `docker`, and `k8s`.
- **CI/CD Pipelines & Previews**: Multi-stage automated pipelines and live multi-device deployment previews.
- **Microservices & Multi-Region Persistence**: Live service mesh telemetry and multi-region consensus failover testing.

### 📦 Assets Included
- `app-debug.apk`: Ready-to-install Android package for Android 7.0+ (API 24+)
